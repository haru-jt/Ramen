山岡家 3Dシミュレーター（Three.js版）

【起動方法】
1. ZIPを解凍します。
2. yamaokaya_threejsフォルダ内でターミナル／コマンドプロンプトを開きます。
3. 次を実行します。
   python -m http.server 8000
4. ChromeまたはEdgeで http://localhost:8000 を開きます。

※ Three.jsをCDNから読み込むため、初回起動時はインターネット接続が必要です。
※ 画面が黒いままの場合は、Chrome/EdgeのハードウェアアクセラレーションとWebGLが有効か確認してください。
※ 本作はファンメイドのシミュレーターであり、山岡家公式のソフトウェアではありません。
