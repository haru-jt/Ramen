# 山岡家 3Dシミュレーター（Three.js / WebGL）

## 起動方法
1. ZIPを展開します。
2. `index.html` をローカルサーバー経由で開きます。
   - Pythonがある場合、フォルダ内で `python -m http.server 8000`
   - ブラウザで `http://localhost:8000` を開きます。
3. インターネット接続が必要です（Three.jsをCDNから読み込みます）。

## 操作
- PC：W/A/S/D または矢印キーで移動、画面ドラッグで視点変更
- スマホ：左下の仮想ジョイスティックで移動、画面ドラッグで視点変更
- 画面下のアクションボタンで入店、食券購入、注文、調理見学、実食を進めます。
- 券売機をタップしてもメニューを開けます。

## 内容
- Three.jsによるWebGL 3Dシーン
- 店舗内装、看板、入口、券売機、厨房、調理スタッフ、カウンター、椅子
- 立体ラーメン（丼、スープ、麺、チャーシュー、ネギ、海苔、湯気）
- 食券購入、麺・脂・味の注文、調理工程、食べ進みによる具材の減少、完食結果

## 注意
これはオリジナルのファンメイド・プロトタイプです。山岡家の公式ゲームではありません。
店舗の正確な図面・公式3Dデータ・実際の券売機画面を複製したものではなく、雰囲気を参考にした簡易モデルです。
Three.jsはCDNから読み込むため、初回起動時にネット接続が必要です。
